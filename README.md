# Yggdrasil

Linux 下的多线程目录复制工具，支持查看目录结构，并使用固定大小的线程池并发复制文件。

## 功能

- 以树形结构展示目录内容，并统计文件和子目录数量
- 复制单个文件或整个目录
- 使用 5 个工作线程并发复制文件
- 汇总复制成功和失败数量

## 编译

依赖 Linux、GCC、CMake 和 POSIX 线程库（pthread）。

```bash
cmake -S . -B build
cmake --build build -j
```

编译后可执行文件为 `build/main`。

## 使用

```text
./build/main <源文件或源目录>
./build/main <源文件或源目录> <目标目录>
```

只提供源路径时，程序展示目录树：

```bash
./build/main "./Yggdrasil/白蜡树"
```

提供源路径和目标目录时，程序执行复制：

```bash
mkdir -p /tmp/yggdrasil-output
./build/main "./Yggdrasil/白蜡树" /tmp/yggdrasil-output
```

目录复制会在目标目录下创建一个同名源目录，例如：

```text
/tmp/yggdrasil-output/白蜡树/
```

复制单个文件时，文件会放在目标目录下，并保留文件名：

```bash
./build/main "/path/to/report.txt" /tmp/yggdrasil-output
```

## 实现概览

### 目录树构建

程序使用“孩子-兄弟”结构保存目录树：每个节点记录第一个子节点、下一个兄弟节点和父节点。目录扫描通过 `opendir`、`readdir` 完成，跳过 `.` 和 `..`。

目录树的构建、展示和复制遍历使用显式栈，而不是递归，以减少深层目录导致调用栈耗尽的风险。路径拼接会处理末尾斜杠，避免重复添加 `/`。

当前扫描根据 `dirent.d_type` 识别目录和普通文件；其他类型的目录项不会作为子项加入目录树。

### 线程池与任务队列

目录遍历遇到文件时，会为该文件创建一个复制任务并加入单向链表队列。线程池启动 5 个工作线程；工作线程从队列取出任务后调用 `copy_file`。

队列由互斥锁保护，并使用条件变量协调生产者和消费者：

- 队列为空时，工作线程等待新任务。
- 队列达到上限时，任务生产者等待空位，避免待处理任务无限增长。
- 工作线程取走任务后通知生产者；加入任务后通知工作线程。
- 关闭线程池时会唤醒工作线程，并等待队列中的任务处理完成后再回收线程。

任务队列最多容纳 1023 个待处理任务；队列满时会等待，不会仅因队列暂满就丢弃任务。

### 固定内存池

任务节点和目录树节点分别使用固定内存池，内存由程序启动时的静态数组提供。分配时优先使用连续空闲块；释放的任务节点会链接到空闲链表中供后续复用。

当前容量由 `mytypes.h` 中的常量决定：

- `MAX_TASK`：1024 个任务节点内存块，其中一个用于队列头节点。
- `MAX_TREE`：2048 个目录树节点内存块。
- `MAX_FILENAME`：512 字节的节点路径缓冲区。

目录树节点在本次运行期间不会回收，因此输入规模超过内存池容量时，目录树可能无法完整构建。

### 文件复制

每个复制任务使用 `open` 打开源文件，并以 `O_CREAT | O_EXCL` 创建目标文件。文件内容通过 2048 字节缓冲区循环读取和写入；写入使用循环处理短写，读取或写入失败会计为失败任务。

成功和失败计数由原子操作更新。主线程会在线程池处理完剩余任务后打印最终统计。

## 边界处理与限制

- 目录项 `.` 和 `..` 会被跳过。
- 子项路径拼接时会检查长度；超过 512 字节的路径会报错并跳过。
- 源目录路径保存在 512 字节缓冲区中，但根路径的复制目前没有长度检查；过长路径可能导致越界。
- 目标路径缓冲区为 1024 字节，过长目标路径没有完整的长度校验，可能被截断。建议使用较短的源路径和目标路径。
- 目录树和遍历栈容量有限。超出 `MAX_TREE` 后，目录树可能不完整；部分栈容量不足的情况也没有统一的错误汇总。
- 扫描依赖 `d_type`；符号链接以及文件系统返回的 `DT_UNKNOWN` 项不会按普通文件或目录处理。
- 如果源路径无法访问，目录打开失败时目前会跳过该目录；无效源路径不一定会得到明确的错误汇总。
- 目标中已存在同名文件时，`O_EXCL` 会阻止覆盖，文件计为复制失败。复制中途发生读写错误时，已创建的部分目标文件不会自动删除。
- 程序复制文件内容，不保留源文件权限、时间戳等元数据；新建权限受系统 `umask` 影响。
